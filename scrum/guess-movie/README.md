# Угадай кино

Кино-викторина: смешанные вопросы (кадр, постер, цитата, саундтрек), 4 варианта ответа, таймер,
показ правильного ответа с автопереходом и итоговый счёт.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # юнит-тесты игровой логики (Vitest)
npm run build    # production-сборка в dist/
```

## Что сделано в спринте 1 (задачи бэклога 1–5)

| № | Задача | Где в коде |
|---|--------|-----------|
| 1 | Главная с кнопкой «Играть» | `src/pages/HomePage.tsx` |
| 2 | Банк вопросов (тип, медиа, варианты, ответ, жанр, сложность) | `src/types/question.ts`, `src/data/questions.ts` |
| 3 | Экран вопроса: медиа, 4 варианта, таймер 15 с | `src/pages/GamePage.tsx`, `src/components/` |
| 4 | Правильный ответ, пауза 3 с, автопереход | `src/components/RevealPanel.tsx` |
| 5 | Подсчёт очков и экран результата | `src/game/quiz.ts`, `src/pages/ResultPage.tsx` |

Игровая логика (сбор раунда, reducer состояний `answering → reveal → finished`) — чистые функции
в `src/game/`, покрыты тестами `src/game/quiz.test.ts`.

## Что сделано в спринте 2 (задачи бэклога 6 и 8)

| № | Задача | Где в коде |
|---|--------|-----------|
| 6 | Каталог викторин с фильтрами по типу вопросов, жанру и сложности | `src/pages/CatalogPage.tsx`, `src/game/filters.ts` |
| 8 | Бонус за скорость правильного ответа | `src/game/quiz.ts`, `src/pages/ResultPage.tsx` |

Из главного меню можно открыть каталог или сразу запустить смешанную викторину. Каталог применяет
выбранные фильтры вместе. Если подходят от 1 до 9 вопросов, раунд короче обычного. При отсутствии
совпадений можно сбросить фильтры. Кнопка «Сыграть ещё» запускает новый раунд с теми же условиями.

За верный ответ начисляется 100 очков плюс до 50 за скорость. Первые 2 секунды бонус равен 50 очкам,
затем он пропорционально уменьшается в течение оставшихся 13 секунд и округляется до целого.
Ошибка и истечение времени дают 0 очков. На итоговом экране число верных ответов, сумма очков
и бонус показаны отдельно.

Стили — CSS Modules + дизайн-токены (CSS-переменные) в `src/styles/tokens.css`.
